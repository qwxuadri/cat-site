# МурГід — сайт про котів

Навчальна робота з «Веб-технологій». Сайт із трьох сторінок:

| Сторінка | Файл | Що на ній |
|---|---|---|
| Головна | `index.html` | текст абзацами: історія дружби людини й кішки, чому ми любимо котів, посилання на дві інші сторінки |
| Породи | `breeds.html` | 6 порід: країна, місце, рік появи й цікава історія походження |
| Кому підходить | `choose.html` | вступ про те, що не кожен кіт підходить кожному, і опитування: відповіді → «Готово» → порода, яка підходить |

## Структура
```
index.html
breeds.html
choose.html
css/style.css   — усі стилі
js/choose.js    — підрахунок балів для опитування
img/            — фото котів і банер для головної
```

## Що використано
- **CSS-змінні** (`:root`, `var(--...)`) для кольорів і відступів — щоб змінити кольори, достатньо поміняти їх в одному місці
- **Flexbox** — шапка, меню, факти-«таблетки», варіанти відповіді, кнопки
- **CSS Grid** — блок «Куди вирушити далі» (1 → 2 колонки), порода (картинка + текст), результат підбору, варіанти відповіді (`repeat(auto-fit, minmax(...))` — колонки рахуються самі, без медіазапиту)
- **clamp()** — заголовки й великий вступний текст плавно ростуть разом з екраном
- **Медіазапити** (mobile first, у `rem`):
  - до 37.5rem (600px) — телефон: усе в одну колонку
  - від 37.5rem — планшет: шапка в один рядок, у результаті картинка поруч із текстом
  - від 56.25rem (900px) — комп'ютер: дві колонки на головній, картинка породи ліворуч від тексту
- Зображення з `alt`, `width`/`height`, `loading="lazy"`; видимий фокус для навігації клавішею Tab
- Фото різних пропорцій показуються в однаковій рамці 4:5: `aspect-ratio: 4 / 5` + `object-fit: cover`

## Як працює підбір кота
Кожна відповідь у формі має атрибути:
- `data-points="british:2 persian:1"` — скільки балів вона дає кожній породі;
- `data-no="siamese bengal"` — породи, які з такою відповіддю точно не підходять (наприклад, якщо людина працює понад 10 годин).

Після натискання «Готово» `js/choose.js` складає бали, відкидає породи з `data-no` і показує ту, що набрала найбільше.

Перевірено на ширині 320, 375, 768 і 1280 px: горизонтального скролу немає.

## Як викласти на GitHub Pages
1. На github.com створіть публічний репозиторій (наприклад `cats-site`).
2. Завантажте в нього всі файли й теки (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через хвилину сайт буде за адресою `https://ВАШ-НІК.github.io/cats-site/`. Це посилання додайте до роботи.
